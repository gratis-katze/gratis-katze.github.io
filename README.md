# felix-site

Statische persönliche Website (kein Build-Schritt), gehostet über GitHub Pages.

- `index.html` – Startseite
- `css/style.css`, `js/main.js`
- `games/` – pro Spiel ein Unterordner mit eigener `index.html`, z. B. `games/snake/index.html`

Lokal ansehen: `python3 -m http.server` im Projektordner.
